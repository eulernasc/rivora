# RIVORA

**Operation Automation System**

PWA pessoal para centralizar processos, automações, tarefas, retornos e rotinas operacionais.

## Stack

- React + TypeScript
- Vite
- Vite PWA
- Lucide Icons
- GitHub Pages

## Status

MVP funcional em desenvolvimento. Integrações reais com Microsoft 365, SharePoint, Outlook, Power Automate e Todoist serão adicionadas por etapas.
